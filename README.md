# 후불결제 연습하기

부릉플러스 기사앱의 후불결제를 **직접 눌러보며 익히는 연습 페이지**입니다.
쿠팡이츠 `배달 시뮬레이션`, 배민 `연습하기`와 같은 방식입니다.

- **표지 → 갈래 고르기 → 앱 화면 위 «같이 연습해볼까요?» 모달** 순서로 시작합니다
  (쿠팡이츠 «첫 배달 체험», 배민 «연습하기»와 같은 자리)
- 화면 위 **흰 안내 띠**에 상황 한 줄 + 할 일 한 줄(눌러야 할 것은 파랑), 오른쪽에 `n / 총`, 맨 위에 진행 막대
- **눌러야 할 곳만 남기고 화면이 어두워지고**, 그 자리에 **손 모양**이 붙습니다 (배민 `연습하기`)
- 다른 곳을 누르면 넘어가지 않고 안내 띠가 한 번 흔들립니다
- `이전으로` · `처음으로`는 **프레임 안 맨 위**에 둡니다 — 기사님이 폰으로 보기 때문에 프레임 밖이면 엄지가 닿지 않습니다

**대상은 기사(라이더)**입니다. 한 단계에 한 동작만 시키고, 정책 설명은 배너 아래 한 줄로만 붙였습니다.

| | |
| --- | --- |
| 결과물 | `dist/index.html` — **단일 HTML 한 장**(약 240KB). 외부 요청 0, 지도 이미지까지 data URI로 내장 |
| 만들기 | `node build.mjs` |
| 보기 | 파일을 그냥 열거나, 아무 정적 호스팅에 올리면 됩니다 |

## 연습 갈래

| # | 갈래 | 단계 | 다루는 것 |
| --- | --- | --- | --- |
| 1 | 현금 결제 | 4 | 현금 확인 얼럿 → 완료. **M캐시 차감** |
| 2 | 카드 결제 | 22 | 앞: **KIS Pay 앱** → 화면 이동 → **카메라결제** → 카드 비추기 → 승인 영수증 → 복귀<br>뒤: **카드 직접 입력 → 이지체크(KICC)** → 가맹점 정보 → 리더기 등록 취소 → 카드번호(보안 키패드) → 금액 → 서명(가로) → KICC 승인 → **결제완료의 `확인`** → 오류 창 대처 |
| 3 | 분할 결제 | 14 | 다른 방법으로 결제 → 분할 시트(키패드) → 현금 20,000원 → **배달지 화면 복귀(잔여 금액)** → 다시 결제하기 → 남은 38,500원 카드 |
| 4 | 현금영수증 발급 | 9 | **지도에서 `수행목록`** → 배달 건의 결제내역 → 발급번호 입력(개인/사업자) → **KIS Pay 현금영수증** → 발행 → 영수증 → **`발급중` 로딩** → 결제 내역(버튼 꺼짐 + 토스트) |

카드는 기사가 두 방법을 다 만나므로 **한 갈래에서 이어서** 연습합니다 —
KIS Pay로 한 건 받고, 곧바로 "이번엔 리더기가 없어요"로 이어져 이지체크를 해봅니다.

기준 금액은 **58,500원**(상품가액 57,600 + 컵 보증금 900)으로 전 갈래가 같습니다.

## 짚은 포인트

- **이지체크 결제완료 화면의 `확인`을 눌러야** 부릉플러스에 결제 결과가 들어갑니다.
  그냥 나가면 결제가 안 된 것으로 남습니다 — 카드 결제 갈래에서 가장 강하게 안내합니다.
- **KIS Pay / 이지체크로 넘어간 금액은 부릉플러스에서 온 값**이라 기사가 고치지 않습니다.
- **KIS Pay의 `블루투스결제`가 카드 리더기**입니다. 리더기가 없으면 `카메라결제`로 카드를 비춰 받습니다.
- **KIS Pay 앱이 안 될 때 `카드 직접 입력`(이지체크)** 으로 받을 수 있다는 걸 먼저 알려줍니다.
- **카메라 결제는 실물 카드 여부를 확인**해야 합니다 (KIS Pay 화면의 안내 문구).
- **분할은 회차마다 방법을 따로** 고릅니다. 한 회차를 받으면 **시트가 다시 열리는 게 아니라
  배달지 화면으로 돌아오고**, 거기서 `결제하기`를 다시 누르면 남은 금액이 미리 채워진 시트가 열립니다.
- **현금은 받은 만큼 M캐시에서 차감**되고, 취소는 VCC 전화로만 됩니다.
- **현금영수증은 현금으로 받은 건에만** 버튼이 있고, 중복 접수되면 기사가 못 고치고 VCC 문의입니다.

## 파일

```
src/base.css      페이지 껍데기 · 폰 프레임 · 안내 배너 · 탭 강조
src/screens.css   화면 스타일 (부릉플러스 / KIS Pay / 이지체크)
src/icons.js      인라인 SVG 아이콘
src/assets/map.jpg  배달지 상세·완료 화면 뒤 지도 (실제 앱 캡처, 빌드할 때 data URI로 들어감)
src/screens.js    화면을 그리는 함수들 — state를 받아 HTML 문자열을 돌려줍니다
src/steps.js      연습 갈래와 단계 정의 (여기만 고쳐도 대부분의 수정이 됩니다)
src/app.js        진행 엔진 — 시작 화면 → 단계 → 마무리 화면, 탭 강조, 크기 맞춤
src/shell.html    합쳐 넣을 껍데기
build.mjs         위 조각들을 dist/index.html 한 장으로 합칩니다
```

**문구·순서를 고칠 일이 가장 많으니 `src/steps.js`부터 보세요.** 한 단계는

```js
{
  screen: 'cardSheet',          // screens.js의 함수 이름
  state: { order: 'card', total: 58500 },
  q: '카드로 받는 방법은 두 가지예요',   // 안내 띠 윗줄 — 지금 상황
  a: '<b>KIS Pay 결제</b>를 눌러주세요', // 안내 띠 아랫줄 — 할 일. <b>는 파랗게 강조됩니다
  note: '…',                    // 알아둘 것 (선택)
  target: '#c-kispay',          // 눌러야 하는 요소
}
```

`auto: 1500`을 주면 누를 것 없이 그 시간 뒤 자동으로 넘어가고(결제 진행중·KICC 스플래시),
`type: { expect: 20000 }`을 주면 키패드로 그 금액을 채울 때까지 기다립니다(분할 결제).

**`tip: { title, desc }`** 를 주면 누르는 대신 **말풍선으로 설명만 하고 `다음`으로** 넘어갑니다
(쿠팡이츠 시뮬레이션과 같은 방식). 강조한 자리를 삼각형으로 가리키고, 위에 자리가 없으면 아래에 붙습니다.
지금은 두 군데에 쓰고 있습니다 — 카드 결제 시트의 두 갈래 안내, KIS Pay 결제수단 안내.

## 확인이 필요한 것

1. **KIS Pay와 이지체크가 갈리는 기준** — 지금은 `카드 결제` 시트에서 기사가 고르는 것으로 그렸습니다.
   단말·가맹점에 따라 자동으로 갈리는 거라면 카드 결제 갈래의 도입부를 바꿔야 합니다.
2. **이지체크 첫 사용 시 `가맹점 다운로드`(TID·사업자번호 입력)** — 최초 1회 등록 절차가 있는데
   연습에는 넣지 않았습니다. 기사 교육에 필요하면 갈래를 하나 더 만들면 됩니다.
3. 완료 화면의 배송수수료·미션 숫자는 캡처값 그대로라 예시입니다.
   KIS Pay 승인 영수증의 가맹점 정보(사업자번호·가맹점번호·단말기번호)도 디자인의 예시값이고,
   가맹점명과 금액만 연습 기준(메쉬프랜차이즈1 · 58,500원)에 맞춰 바꿨습니다.
   승인 종류는 디자인이 `삼성페이 승인`이라 **`카메라 결제 승인`은 제 추정**입니다.
5. **이지체크 서명 화면(1346:124993)은 디자인이 20,000원 사례**라 `5만원 이하 무서명가맹점입니다.`가 떠 있습니다.
   연습 금액은 58,500원이라 그대로 쓰면 틀린 안내가 되므로, **5만원을 넘으면 서명란을 그리도록** 했습니다 —
   **이 서명 화면은 디자인을 받지 못해 제 추정**입니다. 실제 화면을 주시면 맞추겠습니다.
4. 분할 결제의 컵 보증금 표기(900원)와 회차 수 상한.
   카메라 결제 화면은 실제 카메라를 쓸 수 없어 **카드 도형으로 대신**했습니다.
   이지체크 보안 키패드의 숫자 배열은 매번 섞이지만, 연습에서는 디자인과 같은 배열로 고정했습니다.
6. 현금영수증 플로우의 **서버 반영 실패(`재전송`) · 중복 접수 · 발급 취소**는 화면만 확인하고
   연습에는 넣지 않았습니다 (2026-09-17 이재이: 중복 얼럿은 빼기로).
5. **아직 핸드오프를 대조하지 않은 화면** — 결제 방법 시트(어떻게 결제하시겠어요?),
   분할 결제 시트, 완료 화면, KIS Pay 앱, 이지체크 앱은 플로우 시트 캡처를 보고 그렸습니다.
   해당 노드를 주시면 맞추겠습니다.
